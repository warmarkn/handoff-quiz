# Handoff Quiz

A single-page iPhone web app that turns a patient handoff (.docx or pasted text) into quizzes and flashcards to help memorize patient details.

All processing happens on the device. The page's Content-Security-Policy blocks every network connection, nothing is written to storage, and data is held only in memory until you tap Clear, close the tab, or stay away from the app for more than 15 minutes. This repository contains only the app code, no patient data.
